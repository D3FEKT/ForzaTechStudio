## Tools

| Guide | Description |
|---|---|
| [3D Viewer](3d-viewer.md) | Interactive 3D viewport - meshes, skeletons, locators, animations |
| [Carbin Editor](carbin-editor.md) | Open and rebuild `.carbin` car bundle archives, parts hierarchy, and model references |
| [Modelbin Editor](modelbin-editor.md) | Inspect and modify `.modelbin` blobs, materials, and shader parameters |
| [Conversion Tool](conversion-tool.md) | Batch convert assets between Forza game versions, including Advanced VLay patching |
| [Lights Editor](lights-editor.md) | Edit `lights.bin` light entries and `LightPresets.bin` preset parameters |
| [Manufacturer Colors](manufacturer-colors.md) | View and edit `ManufacturerColors.bin` factory paint palettes and material masks |
| [Physics Definition](physics-definition.md) | View, generate, and edit `physicsdefinition.bin` collision shapes |
| [FXB Viewer](fxb-viewer.md) | Browse FX Bank (`.fxb`) effect hierarchies - effects, phases, components, properties |
| [BXML Editor](bxml-editor.md) | Open, edit, and export Binary XML files |
| [Car Scene XML](car-scene-xml.md) | Multi-format editor for ShakeBones, Locators, CarAttributes, IKAnchorBones, and AvPins XML files |
